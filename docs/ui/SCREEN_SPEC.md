# 하루숙제 화면 기획서

> 문서 버전: v1.0  
> 작성일: 2026-08-25  
> 목적: Figma MCP 화면 제작 및 MVP 구현의 기준 정의  
> 관련 문서: `REQUIREMENTS.md`  
> 지원 화면: 모바일, 태블릿, PC 웹

## 1. 이번 작업 범위

이번 Figma 작업에서는 아래 3개 화면과 화면에 필요한 주요 상태를 설계한다.

| ID | 화면명 | 목적 | 주요 사용자 |
|---|---|---|---|
| S01 | 테스트 사용자 선택 | 로그인 없이 학생 또는 학부모 테스트 사용자로 진입 | 학생, 학부모 |
| S02 | 날짜별 숙제 메인 | 날짜별 숙제 조회, 상태 필터, 숙제 등록 진입 | 학생, 학부모 |
| S03 | 숙제 등록 | 과목, 제목, 상세내용, 마감일을 입력해 숙제 생성 | 학생, 학부모 |

숙제 상세·수정·삭제, 변경 이력, 월간 달력, 과목 관리, 실제 인증은 이번 Figma 작업 범위에서 제외한다. 단, S02의 숙제 카드는 이후 상세 화면으로 연결할 수 있는 형태로 설계한다.

## 2. 검토 결과 및 기획 보완 사항

### 2.1 용어 정리

- 실제 인증 절차가 없으므로 S01의 기능명은 `로그인`이 아니라 `테스트 사용자 선택`으로 정의한다.
- 화면 제목이나 안내 문구에는 `학생으로 시작`, `학부모로 시작`을 사용한다.
- 사용자가 입력하는 날짜는 기존 데이터 모델에 맞춰 `완료일`보다 `마감일`로 표현한다.
- 상태명은 `전체`, `완료`, `진행 중`, `미완료`, `기한 지남`으로 통일한다.

### 2.2 역할별 처리

- 학생과 학부모의 S02 레이아웃과 기능은 동일하다.
- 학생으로 진입하면 본인의 숙제를 표시한다.
- 학부모로 진입하면 선택 카드에 연결된 학생 1명을 함께 표시하고, 진입 후 해당 학생의 숙제를 표시한다.
- 학부모 화면에서는 혼동 방지를 위해 프로필 영역에 `OOO 학생의 숙제` 문구를 표시한다.
- 학부모가 숙제를 등록한 경우 목록 카드에 `학부모 등록 · 홍길동`과 같은 작성 주체 라벨을 표시할 수 있도록 공간을 확보한다.
- 여러 학생 전환 기능은 이번 범위에서 제외하고 후속 기능으로 둔다.

### 2.3 기존 시안에서 수정할 항목

- 학교·학년, 알림, 연속 학습 기록, 중요도 라벨은 데이터와 정책이 확정되지 않아 숨긴다.
- 동작하지 않는 `월 단위` 선택은 숨기고 주간 날짜 탐색만 제공한다.
- 상태 요약에 `기한 지남`을 추가해 총 5개로 구성한다.
- 마감 시간 데이터는 없으므로 `오후 5시까지` 대신 `오늘`, `내일`, `8월 28일까지`, `기한 지남`처럼 날짜로 표시한다.
- `카드를 눌러 진행률을 바꿔보세요` 문구는 제거한다. 카드 선택은 추후 상세 화면 이동 용도로 사용한다.
- 과목 필터와 숙제 추가 버튼은 명확한 텍스트 라벨을 사용한다.

## 3. 전체 사용자 흐름

```text
S01 테스트 사용자 선택
  ├─ 학생 선택 → 학생으로 시작 ─┐
  └─ 학부모 선택 → 학부모로 시작 ┤
                                 ▼
                      S02 날짜별 숙제 메인
                        ├─ 날짜 선택 → 해당 날짜 목록 갱신
                        ├─ 상태 선택 → 목록 필터
                        ├─ 과목 선택 → 목록 필터
                        └─ 숙제 추가 → S03 숙제 등록
                                           ├─ 저장 → 대상 날짜의 S02
                                           └─ 취소/뒤로 → 기존 S02
```

브라우저 새로고침 시 마지막 테스트 사용자를 세션에 유지할 수 있다. 사용자 변경은 S02 프로필 메뉴의 `사용자 변경`을 통해 S01로 돌아간다.

## 4. 공통 디자인 원칙

### 4.1 디자인 방향

- 초등학생부터 중학생까지 쉽게 이해할 수 있는 친근하고 차분한 분위기
- 기존 시안의 녹색 계열 브랜드 컬러와 밝은 회색 배경을 유지
- 장식보다 날짜, 상태, 숙제 제목과 주요 행동의 정보 위계를 우선
- 카드 모서리는 부드럽게 표현하되 입력 폼과 버튼의 경계는 명확히 구분
- 색상만으로 상태를 전달하지 않고 아이콘과 상태 문구를 항상 함께 표시

### 4.2 접근성 및 사용성

- 주요 버튼과 선택 요소의 최소 터치 영역은 44×44px로 한다.
- 본문 텍스트는 최소 14px, 보조 문구는 최소 12px를 권장한다.
- 키보드 포커스, hover, pressed, disabled 상태를 각각 설계한다.
- 입력 필드는 placeholder만 사용하지 않고 항상 외부 라벨을 제공한다.
- 오류는 필드 테두리, 오류 아이콘, 문구를 함께 사용한다.
- 모바일 320px 너비와 브라우저 200% 확대에서도 가로 스크롤이 생기지 않게 한다.

### 4.3 공통 내비게이션

- PC/태블릿: 왼쪽 날짜 선택 영역 + 오른쪽 콘텐츠 영역
- 모바일: 상단 앱 바 + 날짜 선택 드로어 또는 가로 날짜 스트립 + 단일 콘텐츠 열
- 브랜드 선택 시 S02의 오늘 날짜로 이동
- 프로필 메뉴: 현재 사용자 이름, 역할, `사용자 변경`

## 5. S01 테스트 사용자 선택

### 5.1 화면 목적

실제 아이디와 비밀번호 입력 없이 준비된 테스트 사용자를 선택해 역할별 화면을 확인한다.

### 5.2 화면 구성

1. 브랜드 영역: 로고/심볼, 서비스명 `하루숙제`
2. 안내 영역
   - 제목: `누구로 시작할까요?`
   - 설명: `테스트할 사용자를 선택해 주세요.`
   - 개발 안내 배지: `테스트 모드 · 별도 로그인 없음`
3. 역할 탭 또는 세그먼트: `학생`, `학부모`
4. 사용자 선택 카드 목록
5. 하단 주 행동 버튼
   - 학생 선택 시 `학생으로 시작`
   - 학부모 선택 시 `학부모로 시작`

### 5.3 학생 카드 정보

- 이름: 예) `김하늘`
- 나이: 예) `11세`
- 학부모 이름: 예) `학부모 김민지`
- 아바타 또는 이름 첫 글자
- 선택 상태를 나타내는 라디오 표시와 카드 강조선

학생 데이터는 `이름`, `나이`, `학부모 이름`만 사용한다. 학교와 학년은 표시하지 않는다.

### 5.4 학부모 카드 정보

- 학부모 이름: 예) `김민지`
- 연결 학생: 예) `김하늘 학생`
- 역할 라벨: `학부모`
- 아바타 또는 이름 첫 글자
- 선택 상태를 나타내는 라디오 표시와 카드 강조선

### 5.5 동작 및 상태

| 상태 | 표현 및 동작 |
|---|---|
| 초기 | 기본 역할은 학생, 사용자 카드는 선택하지 않음 |
| 카드 선택 | 카드 전체 강조, 라디오 선택, 시작 버튼 활성화 |
| 역할 변경 | 해당 역할의 사용자 목록으로 교체하고 기존 선택 해제 |
| 미선택 | 시작 버튼 비활성화 |
| 시작 | 선택한 사용자의 세션을 만든 뒤 S02 오늘 날짜로 이동 |
| 로딩 | 카드 스켈레톤과 비활성 시작 버튼 |
| 조회 실패 | `사용자 정보를 불러오지 못했어요.`와 `다시 시도` 버튼 |
| 빈 목록 | `선택할 수 있는 테스트 사용자가 없어요.` 표시 |

## 6. S02 날짜별 숙제 메인

### 6.1 화면 목적

선택 날짜의 숙제를 한눈에 확인하고 날짜·상태·과목으로 목록을 좁히거나 새 숙제를 등록한다.

### 6.2 PC 레이아웃

#### 왼쪽: 날짜 선택 영역

- 서비스 로고와 이름
- 현재 연도 및 주차: 예) `2026년 · 8월 4주`
- 이전 주 / 다음 주 버튼
- 월요일부터 일요일까지 7개 날짜 목록
- 날짜별 숙제 개수 배지
- 선택 날짜, 오늘, 일반 날짜를 서로 다른 시각 상태로 구분
- 하단 `오늘로 이동` 버튼

#### 오른쪽: 콘텐츠 영역

1. 상단 헤더
   - 페이지 인사말
   - 현재 사용자 이름과 역할
   - 학부모일 때 `김하늘 학생의 숙제`
   - 프로필 메뉴 및 사용자 변경
2. 선택 날짜 소개 카드
   - 날짜: 예) `8월 25일 화요일`
   - 요약: 예) `숙제 5개 중 2개를 완료했어요.`
3. 상태 요약/필터
   - `전체`, `완료`, `진행 중`, `미완료`, `기한 지남`
   - 각 항목의 아이콘, 문구, 개수
   - 선택 상태가 명확한 토글 버튼 형태
4. 목록 도구 영역
   - 제목 `숙제 목록`
   - 과목 필터: `전체 과목`, `국어`, `영어`, `수학`, 사용자 과목
   - 주 행동 버튼 `+ 숙제 추가`
5. 숙제 목록

### 6.3 숙제 카드 정보

- 상태 색상 바 또는 상태 아이콘
- 과목 아이콘과 과목명
- 숙제 제목
- 마감일의 상대 표현과 실제 날짜
  - 예) `오늘 · 8월 25일까지`
  - 예) `내일 · 8월 26일까지`
  - 예) `기한 지남 · 8월 23일까지`
- 진행률 `0 / 25 / 50 / 75 / 100%`와 진행 표시줄
- 상태 아이콘과 `완료 / 진행 중 / 미완료 / 기한 지남` 문구
- 학부모가 등록한 항목은 `학부모 등록 · 김민지` 라벨
- 상세 화면 연결을 위한 카드 선택 affordance

상태 계산 순서는 다음과 같다.

1. 진행률이 100%이면 `완료`
2. 진행률이 100% 미만이고 마감일이 오늘보다 이전이면 `기한 지남`
3. 진행률이 25%, 50%, 75%이면 `진행 중`
4. 진행률이 0%이면 `미완료`

### 6.4 주요 동작

| 사용자 행동 | 결과 |
|---|---|
| 날짜 선택 | 선택 날짜 강조 및 소개 카드·요약·목록 갱신 |
| 이전/다음 주 | 날짜 목록을 해당 주로 갱신 |
| 오늘로 이동 | 오늘이 포함된 주와 오늘 날짜 선택 |
| 상태 요약 선택 | 해당 상태만 필터링, 다시 선택하거나 전체 선택 시 해제 |
| 과목 선택 | 선택 과목의 숙제만 표시 |
| 상태+과목 선택 | 두 조건을 AND 방식으로 함께 적용 |
| 숙제 카드 선택 | 후속 범위인 숙제 상세 화면으로 이동 |
| 숙제 추가 | S03으로 이동하며 현재 선택 날짜를 마감일 기본값으로 전달 |

### 6.5 상태별 화면

| 상태 | 표현 |
|---|---|
| 최초 로딩 | 날짜와 숙제 카드 스켈레톤 |
| 숙제 없음 | `이 날짜에는 숙제가 없어요.`와 `숙제 추가` 버튼 |
| 필터 결과 없음 | `조건에 맞는 숙제가 없어요.`와 `필터 초기화` 버튼 |
| 조회 실패 | 오류 안내와 `다시 시도` 버튼 |
| 오프라인 | 상단 배너 `인터넷 연결을 확인해 주세요.` |

### 6.6 반응형

- 1200px 이상: 왼쪽 280~300px 고정 영역, 오른쪽 유동 콘텐츠
- 768~1199px: 왼쪽 240~260px, 요약 카드는 2~3열로 줄바꿈
- 767px 이하: 날짜 영역을 드로어 또는 가로 날짜 스트립으로 전환하고 숙제 카드는 한 열로 표시
- 모바일에서는 상태 요약을 2열 또는 가로 스크롤 칩으로 구성하되 `기한 지남`이 숨겨지지 않게 한다.
- 모바일의 `숙제 추가`는 목록 제목 옆 버튼 또는 화면 하단 고정 버튼 중 하나로 일관되게 사용한다.

## 7. S03 숙제 등록

### 7.1 화면 목적

학생 본인 또는 학부모가 대상 학생에게 새 숙제를 등록한다.

### 7.2 진입 및 종료

- S02의 `숙제 추가` 버튼으로 진입한다.
- S02에서 선택한 날짜를 마감일 기본값으로 사용한다.
- 저장 성공 시 저장한 마감일의 S02로 이동하고 성공 메시지를 표시한다.
- 취소 또는 뒤로 가기 시 입력값이 있으면 `작성 중인 내용을 취소할까요?` 확인 대화상자를 표시한다.

### 7.3 화면 구성

1. 상단 영역: 뒤로 가기, 제목 `숙제 등록`, 설명 `새로운 숙제를 추가해 보세요.`
2. 대상 학생 정보
   - 학생 진입: 본인 이름을 읽기 전용으로 표시
   - 학부모 진입: 연결 학생 이름을 읽기 전용으로 표시
3. 입력 폼
4. 하단 행동: 보조 버튼 `취소`, 주 버튼 `숙제 저장`

### 7.4 입력 항목과 검증

| 순서 | 항목 | 필수 | 입력 방식 | 기본값 및 검증 |
|---:|---|:---:|---|---|
| 1 | 과목 | Y | 선택 카드 또는 드롭다운 | `국어`, `영어`, `수학`, `기타` 중 선택 |
| 2 | 기타 과목명 | 조건부 | 한 줄 입력 | `기타` 선택 시만 노출, 공백 제외 1~30자 |
| 3 | 제목 | Y | 한 줄 입력 | 공백 제외 1~200자 |
| 4 | 상세내용 | N | 여러 줄 입력 | 최대 2,000자, 현재 글자 수 표시 |
| 5 | 마감일 | Y | 날짜 선택 | S02 선택 날짜를 기본값으로 사용, 유효한 날짜 |

새 숙제의 진행률은 자동으로 0%가 되므로 등록 화면에 진행률 입력을 두지 않는다.

### 7.5 과목 선택 상세

- 기본 과목 `국어`, `영어`, `수학`은 동일한 위계의 선택 카드 또는 칩으로 표시한다.
- `기타`를 선택하면 바로 아래에 `과목명을 입력해 주세요` 입력 필드를 펼친다.
- 기타 과목명을 저장하면 현재 학생의 사용자 과목으로 함께 등록되어 이후 과목 목록과 필터에 표시된다.
- 기존 사용자 과목이 있으면 기본 과목과 함께 선택지에 먼저 노출하고, 새 과목 추가용 `기타`를 마지막에 배치한다.
- 같은 학생에게 이미 존재하는 과목명은 중복 등록하지 않고 기존 과목을 사용하도록 안내한다.

### 7.6 폼 상태

| 상태 | 표현 및 동작 |
|---|---|
| 초기 | 필수값이 충족되기 전까지 저장 버튼 비활성화 |
| 필드 오류 | 필드 바로 아래 구체적인 오류 문구 표시, 첫 오류로 포커스 이동 |
| 저장 중 | 저장 버튼 비활성화, `저장 중...`과 진행 표시, 중복 제출 방지 |
| 저장 성공 | `숙제를 등록했어요.` 메시지 후 S02로 이동 |
| 저장 실패 | 작성 내용을 유지하고 상단 오류 안내와 `다시 저장` 제공 |
| 과목 중복 | `이미 등록된 과목이에요. 기존 과목을 선택해 주세요.` 표시 |
| 이탈 확인 | 입력값이 바뀐 경우에만 취소 확인 대화상자 표시 |

### 7.7 반응형

- PC: 최대 너비 720px의 중앙 정렬 폼 또는 메인 콘텐츠 안의 카드형 폼
- 태블릿: 입력 폼 너비를 화면에 맞추고 행동 버튼을 우측 정렬
- 모바일: 한 열 폼, 과목 선택은 2열, 하단 행동 버튼은 화면 너비 전체 사용
- 모바일 키보드가 열린 상태에서도 현재 입력과 오류 문구가 가려지지 않게 한다.

## 8. Figma 제작 기준

### 8.1 필수 프레임

| 구분 | 프레임 크기 | 대상 화면 |
|---|---:|---|
| Desktop | 1440×1024 | S01, S02, S03 |
| Mobile | 390×844 | S01, S02, S03 |

태블릿은 별도 완성 프레임 대신 Auto Layout과 제약 조건으로 대응하되, 필요 시 768px 너비에서 레이아웃을 검증한다.

### 8.2 페이지와 프레임 이름

```text
Page 00_Cover

Page 02_Components
Page 03_Screens

S01_UserSelect_Desktop_Default
S01_UserSelect_Mobile_Default
S02_Home_Desktop_Default
S02_Home_Desktop_Empty
S02_Home_Mobile_Default
S03_HomeworkCreate_Desktop_Default
S03_HomeworkCreate_Desktop_Error
S03_HomeworkCreate_Mobile_Default
```

### 8.3 필수 컴포넌트

- Button: Primary / Secondary / Ghost / Icon, 각 Default / Hover / Pressed / Focus / Disabled / Loading
- Input: Text / Textarea / Date, 각 Default / Focus / Filled / Error / Disabled
- Segmented control: 학생 / 학부모
- User selection card: Student / Parent, Default / Selected
- Subject option: Default / Selected / Custom
- Date item: Default / Today / Selected / Has homework
- Summary filter: All / Done / Doing / Todo / Overdue, Default / Selected
- Homework card: Done / Doing / Todo / Overdue / Parent-created
- Badge: Role / Parent-created / Count
- Feedback: Toast / Inline error / Error banner / Empty state / Skeleton
- Dialog: 작성 취소 확인

모든 목록과 폼은 Auto Layout을 사용하고, 텍스트 길이가 늘어나도 높이가 자연스럽게 확장되도록 설정한다.

### 8.4 프로토타입 연결

- S01 사용자 카드 선택 → 시작 버튼 활성화 → S02
- S02 날짜 선택 → 선택 상태가 다른 S02 variant
- S02 상태 요약 선택 → 필터 variant
- S02 숙제 추가 → S03
- S03 기타 선택 → 기타 과목명 입력 노출
- S03 저장 → 성공 토스트가 있는 S02
- S03 취소 → 이탈 확인 Dialog → S02 또는 계속 작성

## 9. 화면 검수 기준

- 학생과 학부모 테스트 사용자를 비밀번호 없이 선택해 S02로 이동할 수 있다.
- 학생 카드에는 이름, 나이, 학부모 이름이 표시된다.
- 학부모로 진입해도 S02 구조는 같고 대상 학생과 현재 역할을 구분할 수 있다.
- PC에서 왼쪽 날짜 영역과 오른쪽 콘텐츠 영역이 분명히 구분된다.
- `전체/완료/진행 중/미완료/기한 지남` 5개 상태가 아이콘과 문구로 구분된다.
- 숙제 등록에서 국어, 영어, 수학을 선택할 수 있다.
- `기타` 선택 시 과목명을 직접 입력할 수 있고 중복·빈 값 오류 상태가 있다.
- 제목, 마감일 필수 검증과 상세내용 글자 수 상태가 디자인되어 있다.
- 로딩, 빈 목록, 조회 실패, 저장 중, 저장 실패 상태가 포함되어 있다.
- Desktop 1440px과 Mobile 390px 프레임 사이에서 콘텐츠 우선순위와 기능이 유지된다.
- 주요 조작 영역은 44×44px 이상이며 키보드 포커스 상태가 정의되어 있다.
